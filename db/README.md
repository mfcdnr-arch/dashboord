# База данных Dashboard

PostgreSQL 16 (локально в dev — образ 15, прод-цель 16). Единственное хранилище системы.

## Миграции

Каталог `db/migrations/` — упорядоченные SQL-миграции. Применяются по возрастанию номера:

| Файл | Что создаёт |
|------|-------------|
| `001_core.sql` | Организации, пользователи, роли, папки, дашборды, виджеты, версии; слой прав (securable_objects/object_acl), `fn_resolve_access`, уведомления, аудит |
| `002_lifecycle.sql` | Документы → извлечение таблиц/столбцов → выпуски датасетов → метрики/версии → версии виджетов → публикация |
| `003_roles_flags.sql` | Флаги ролей `can_edit_formulas`, `can_moderate` |
| `004_access_grants.sql` | Гранты доступа на уровне дашборда и виджета; правило segregation of duties для формул |
| `005_abac.sql` | ABAC-теги (задел на row-level, отложено) |
| `006_moderation.sql` | Жизненный цикл модерации: статусы, правила переходов, причины возврата, сессии, чек-лист |

## Применение

**Автоматически** — при первом старте пустого тома Postgres миграции монтируются в
`/docker-entrypoint-initdb.d` и выполняются автоматически (см. `docker-compose.yml`).

**Вручную** (на уже работающий контейнер):

```bash
./db/apply_migrations.sh
```

Скрипт накатывает все `*.sql` по порядку с `ON_ERROR_STOP=1`.
