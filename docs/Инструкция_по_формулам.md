# Инструкция по формулам метрик

> Для модераторов и администраторов Dashboard. Как задать формулу показателя (KPI)
> в текстовом режиме. Визуальный конструктор («собери мышкой») появится отдельно —
> эта инструкция про текстовый ввод.

---

## 1. Где писать формулу

**Раздел «Метрики» → выбрать/создать метрику → блок «Новая версия формулы».**

1. Создайте метрику (код латиницей + название).
2. В поле «Новая версия формулы» введите формулу.
3. Нажмите **«Предпросмотр»** — система посчитает результат на реальных данных
   и покажет, из чего он собран. **Всегда проверяйте предпросмотром до сохранения.**
4. Нажмите **«Сохранить версию»** — создастся черновик.
5. Проведите версию по статусам: **Проверить** → **Одобрить**
   (одобрить может только другой человек, не автор — защита от ошибок).

---

## 2. Из чего состоит формула

Формула собирается из четырёх «кирпичиков»: **данные**, **действия**, **функции**, **фильтры**.

### 2.1. Ссылки на данные — откуда берутся числа

| Запись | Что означает |
|--------|--------------|
| `field('датасет','поле')` | весь столбец `поле` из последнего выпуска датасета `датасет`. Обычно оборачивается в функцию (SUM и т.п.) |
| `cell('датасет', date='ГГГГ-ММ-ДД', row='Название строки', col='поле')` | одна ячейка: выпуск за конкретную дату, строка **по названию**, столбец `поле` |
| `metric('код')` | значение другой метрики (по умолчанию — одобренной версии) |

- **`датасет`** — это код выпуска, который вы задавали на экране распознавания
  документа (поле «Код»).
- **`поле`** — код канонического поля (столбца), заданный при разметке документа.
- **Ячейка ищется по названию строки, а не по её позиции** — если строки в файле
  сдвинутся, формула не сломается.

Уточнение версии метрики:
```
metric('выручка')                 — одобренная версия (по умолчанию)
metric('выручка', version=latest) — самая свежая версия
metric('выручка', version=3)      — конкретная версия №3
```

### 2.2. Действия (арифметика)

`+` сложить · `−` вычесть · `*` умножить · `/` разделить · `^` возвести в степень ·
`( )` скобки для группировки.

**Порядок вычислений** (как в математике): сначала `^`, затем `*` и `/`,
затем `+` и `−`. Скобки меняют порядок:
```
2 + 3 * 4        = 14      (сначала умножение)
(2 + 3) * 4      = 20      (сначала скобки)
```

### 2.3. Функции

**Свёртка столбца** (превращает столбец чисел в одно число):

| Функция | Результат |
|---------|-----------|
| `SUM(field(...))` | сумма |
| `AVG(field(...))` | среднее |
| `COUNT(field(...))` | количество значений |
| `MIN(field(...))` | минимум |
| `MAX(field(...))` | максимум |

**План / факт:**

| Функция | Результат |
|---------|-----------|
| `PLAN_FACT_DELTA(план, факт)` | отклонение: `факт − план` |
| `PLAN_FACT_PCT(план, факт)` | выполнение плана в процентах: `факт / план * 100` |

**Процент / доля** (одно число — 100%, второе — сколько процентов от него):

| Функция | Результат |
|---------|-----------|
| `PERCENT_OF(база, значение)` | `значение / база * 100`. База принимается за 100%. Пример: `PERCENT_OF(200, 50)` = 25. |

Примеры:
```
# Доля «Паспорт РФ» от всех принятых (сколько % Паспорт от общего)
PERCENT_OF(SUM(field('нагрузка','принято')),
           SUM(field('нагрузка','принято'), filter={'услуга'='Паспорт РФ'}))

# Тот же смысл через обычную арифметику
SUM(field('нагрузка','принято'), filter={'услуга'='Паспорт РФ'})
  / SUM(field('нагрузка','принято')) * 100
```

### 2.4. Фильтры — выбрать конкретную строку

Внутри свёртки можно ограничить строки по названию:
```
SUM(field('план','кол'), filter={'услуга'='Паспорт РФ'})
```
Возьмёт значения `кол` только по строке «Паспорт РФ».

## 3. Примеры (МФЦ)

```
# Всего принято заявлений
SUM(field('нагрузка','принято'))

# Процент выполнения плана
PLAN_FACT_PCT(SUM(field('план','кол')), SUM(field('факт','кол')))

# Прирост за день (одна ячейка минус другая, по датам)
cell('нагрузка', date='2026-07-11', row='Паспорт РФ', col='принято')
  - cell('нагрузка', date='2026-07-10', row='Паспорт РФ', col='принято')

# Доля одной услуги от общего (через фильтр)
SUM(field('нагрузка','принято'), filter={'услуга'='Паспорт РФ'})
  / SUM(field('нагрузка','принято')) * 100

# Показатель на основе другой метрики
metric('итого_принято') / metric('число_окон')
```

## 4. Предпросмотр и проверка

- **Предпросмотр обязателен.** Он считает результат на реальных данных и показывает
  зависимости (какие датасеты и метрики участвовали). Если результат неожиданный —
  формула написана не так, как задумано.
- Ошибки формулы показываются понятным текстом (например, «Деление на ноль»,
  «Датасет 'план' не найден или не выпущен», «field(...) содержит N значений —
  оберните в агрегат»).

---

## 5. Версии и статусы

Каждая правка формулы — новая **версия**. Жизненный цикл версии:

**черновик** (draft) → **проверена** (validated) → **одобрена** (approved).

- Одобрить версию может **только не-автор** (кто написал — тот не одобряет; защита
  от бесконтрольных изменений).
- При одобрении новой версии прежняя одобренная становится «устарела» (deprecated).
- Ссылка `metric('код')` по умолчанию берёт **одобренную** версию.

## 6. Оконные функции (по периодам)

Работают, когда у датасета несколько выпусков за разные периоды (ось времени —
`reporting_period_start` выпусков). Значение arg считается для каждого периода.

- **`RUNNING_TOTAL(выражение, grain='month')`** — нарастающий итог: сумма значений
  по всем периодам (до последнего). Пример: `RUNNING_TOTAL(SUM(field('nagruzka','prinyato')), grain='month')`
  при 100/120/140 по месяцам → **360**.
- **`PERIOD_COMPARE(выражение, 'month', mode='delta')`** — сравнение последнего периода
  с периодом на 1 единицу назад (`day/week/month/quarter/year`). `mode`: `delta`
  (разница), `pct` (в % к прошлому), `ratio` (отношение). Пример: 140 vs 120 →
  delta **20**, pct **116.67**. Это и есть «месяц-к-месяцу / год-к-году».
- **`SHARE_OF_TOTAL(выражение, over='total')`** — доля последнего периода в сумме по
  всем периодам, %. Пример: 140 из 360 → **38.89%**.

Внутри arg берите `SUM(field(...))` и т.п. (ссылки на датасет задают ось периодов);
`metric()`/`cell()` внутри окна считаются на активном выпуске.

## 7. Ограничения (на текущий момент)

- **Циклы запрещены:** если метрика A ссылается на B, а B — на A, система не даст
  сохранить и покажет цепочку зависимости.

---

## 7. Частые ошибки

| Сообщение | Что делать |
|-----------|-----------|
| `field('...','...') содержит N значений — оберните в агрегат` | добавьте `SUM(...)`/`AVG(...)` вокруг `field(...)` |
| `Датасет '...' не найден или не выпущен` | проверьте код датасета; документ должен быть распознан и выпущен |
| `Нет ячейки: cell(...)` | проверьте дату, название строки и код столбца — они должны точно совпадать с данными |
| `Деление на ноль` | знаменатель равен нулю — добавьте проверку или уточните данные |
| `Обнаружена циклическая зависимость` | уберите ссылку, замыкающую цикл между метриками |
| `Нельзя одобрять собственную версию` | версию должен одобрить другой пользователь |
